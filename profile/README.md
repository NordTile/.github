# NordTile

> Keeping Windows Phone 8.1 and Windows 10 Mobile useful today.

NordTile builds apps and libraries for **Windows Phone 8.1** and **Windows 10 Mobile**: modern networking and security building blocks, and the everyday apps on top of them, written natively for the platform.

## Projects

Repositories are being prepared and will appear here as they are published:

- **Nordigram** — a native messaging client.
- **nordtile-* libraries** — foundation and networking libraries for WinRT apps.
